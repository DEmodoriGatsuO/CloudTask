# 現状の課題

CloudTask の現時点での既知の問題・制限事項・改善が必要な箇所をまとめます。

---

## 機能面

### R2 Storage が未有効化

**状況:** ファイル添付機能（Phase 3）は実装済みだが、Cloudflare R2 バケットの有効化が未完了。

**影響:** ファイルアップロード・ダウンロードが利用不可。API は `requireR2()` ガードで `503 Service Unavailable` を返す。

**対応方針:** Cloudflare Dashboard で R2 を有効化し、`cloudtask-files` バケットを作成する。

---

### ダッシュボードの情報量が不足

**状況:** ダッシュボードはプロジェクト一覧と進捗サマリーのみ表示。

**不足している情報:**
- 期限切れタスクの警告
- 自分が担当しているタスク一覧
- プロジェクト横断のアクティビティフィード

---

### タスク一覧のフィルター・ソートが弱い

**状況:** 現在のタスク一覧はステータス・担当者・優先度でのフィルタリングが基本的なもののみ。

**不足している機能:**
- フリーワード検索
- 複合条件フィルター
- ソート順のカスタマイズ（作成日・更新日・優先度）

---

### モバイル対応が不完全

**状況:** Tailwind CSS によるレスポンシブ対応は部分的に実施済み。

**未対応の箇所:**
- カンバンボードのタッチ操作（ドラッグ&ドロップ）
- ガントチャートの横スクロール操作
- 一部モーダルのモバイル表示

---

## 技術面

### E2E テストが未実装

**状況:** Vitest によるユニットテストは54件実装済み（DB/Utils/Validators）だが、E2Eテストはゼロ。

**影響:** UI フローやAPI統合の回帰テストが手動になっている。

**対応方針:** Playwright の導入を検討。

---

### JWT_SECRET が wrangler.jsonc に記載されていた（解消済み）

**状況:** ポートフォリオ用途として一時的にハードコードされていた。Public公開前に Cloudflare Secrets へ移行済み。

**現状:** `wrangler secret put JWT_SECRET` で管理。`wrangler.jsonc` には含まれない。

---

### Cloudflare KV 利用上限アラート（解消済み）

**状況:** 認証ミドルウェアとレート制限ミドルウェアが全リクエストで KV を使用していたため、無料プランの上限（write: 1,000回/日）に達していた。

**原因の内訳:**
| 操作 | 発生箇所 | 回数 |
|---|---|---|
| SESSIONS read | `middleware/auth.ts` — 全認証済みリクエスト | 1回/リクエスト |
| CACHE read | `middleware/rate-limit.ts` — 全リクエスト | 1回/リクエスト |
| CACHE write | `middleware/rate-limit.ts` — 全リクエスト | 1回/リクエスト |

**対応（実施済み）:**
- `middleware/auth.ts`: KV セッション検索を削除し、JWT 署名・期限検証のみに変更
- `middleware/rate-limit.ts`: KV ベースのレート制限を無効化（pass-through に変更）
- `routes/auth.ts`: ログイン・ログアウト時の KV 書き込み・削除を削除

**トレードオフ:** ログアウト後もJWTトークンは有効期限（7日）まで技術的に有効。ポートフォリオ用途では許容範囲。

---

### バンドルサイズの最適化余地

**状況:** React.lazy + manualChunks でコード分割済み。最大チャンク248KB。

**改善余地:**
- 一部ページで不要なライブラリがバンドルに含まれている可能性
- 画像最適化未実装

---

## 運用面

### エラー監視が未整備

Sentry 等のエラー監視ツールが未導入。本番エラーの把握が Cloudflare Workers のログのみに依存している。

### シードデータの自動リセット

Cronトリガー（毎日 18:00 UTC）でシードデータを定期リセットする仕組みは実装・デプロイ済み（`index.ts` の `scheduled` ハンドラ）。ただし動作確認は未実施。
