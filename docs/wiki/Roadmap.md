# 今後の展望・ロードマップ

CloudTask の今後の改善・機能追加計画をまとめます。
優先度は「ポートフォリオとしての完成度向上」を軸に設定しています。

---

## 近期（高優先度）

### UX 改善

| 項目 | 内容 |
|---|---|
| ダッシュボード充実 | 期限切れタスク警告、担当タスク一覧、横断アクティビティ |
| タスク検索・フィルター強化 | フリーワード検索、複合条件フィルター、カスタムソート |
| モバイル対応 | タッチ操作のカンバンD&D、ガントチャート横スクロール改善 |
| ローディングスケルトン | データ取得中のスケルトン表示で体感速度向上 |

### インフラ

| 項目 | 内容 |
|---|---|
| R2 有効化 | ファイル添付機能の完全有効化 |
| シードデータ自動リセット | Cron + Workers でデモデータを毎日リセット |

---

## 中期（中優先度）

### 機能拡張

| 項目 | 内容 |
|---|---|
| コメントのリッチテキスト対応 | Markdown プレビュー機能 |
| ファイルプレビュー | 画像・PDF のインラインプレビュー |
| @メンション候補のオートコンプリート改善 | 入力補完の精度向上 |
| ガントチャートのタスクバー直接ドラッグ | バーをドラッグして期間を直接変更 |
| ドラッグ&ドロップのアニメーション | 操作感の向上（@dnd-kit のアニメーション活用） |

### テスト

| 項目 | 内容 |
|---|---|
| E2E テスト導入 | Playwright で主要ユーザーフローをカバー |
| サービス層ユニットテスト | API サービス層のテストカバレッジ向上 |
| フック層ユニットテスト | TanStack Query カスタムフックのテスト |

### 観測性

| 項目 | 内容 |
|---|---|
| エラー監視 | Sentry 等の導入 |
| Workers Analytics 活用 | API 利用状況の可視化 |

---

## 長期（将来）

### 新機能

| 項目 | 内容 |
|---|---|
| メール通知 | Cloudflare Email Workers を活用 |
| Slack / Teams Webhook | 外部サービス連携 |
| データエクスポート | CSV/JSON 形式でのエクスポート |
| 監査ログ | 操作履歴の詳細記録・エクスポート |
| SSO 統合 | Cloudflare Access を使ったシングルサインオン |
| 多言語対応 | i18n（英語/日本語切り替え） |

### インフラ

| 項目 | 内容 |
|---|---|
| カスタムドメイン | 独自ドメインの設定 |
| API レスポンスキャッシュ最適化 | KV / Cache API の活用 |
| JWT_SECRET を完全 Secrets 管理へ | Cloudflare Secrets + GitHub Actions Secrets に統一 |

---

## 実装しない・スコープ外

- リアルタイム共同編集（Google Docs スタイル） — Durable Objects のコスト・複雑度が高い
- モバイルアプリ（iOS/Android） — React Native など別スタックが必要
- オンプレミス対応 — Cloudflare Workers 特有の API に依存している設計
